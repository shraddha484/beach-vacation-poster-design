# Beach Vacation Poster Design 🌴

A creative **Beach Vacation promotional poster** designed to showcase a tropical holiday getaway in a visually appealing and engaging format.

## 🎨 Design Overview

This poster uses a vibrant beach theme with:

- Tropical beach background
- Palm trees and ocean scenery
- Bold "BEACH Vacation" typography
- Travel and vacation-themed illustrations
- Polaroid-style destination images
- Highlighted travel package pricing
- Experience and activity section
- Call-to-action section
- Contact and booking information
- QR code area for booking

**Take a Break, Make Memories**
